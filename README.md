# Phoneme Games

Phoneme Games is a frontend web application created for Assessment 1 in Cloud-Based Web Applications.

The application is designed to help teachers create simple phoneme-based classroom activities for Speech Pathology students.

## Features

- Home, About, Wordle, Word Search and Settings pages
- Phoneme-based Wordle activity
- Phoneme-based Word Search activity
- Light and dark themes
- Theme preference stored using cookies
- Hamburger menu for compact navigation
- Playable activity previews
- Standalone HTML file generation for both activities

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
